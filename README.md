# 💳 Credit Wise Loan Approval System

A Machine Learning project that predicts whether a loan application will be **approved or rejected** based on applicant financial, demographic, employment, and loan-related information.

## 🔍 Project Highlights

- Data cleaning and missing value handling
- Exploratory Data Analysis (EDA)
- Categorical encoding and feature scaling
- Feature engineering
- Model training and comparison
- Evaluation using Accuracy, Precision, Recall, and F1 Score

## 🤖 Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

## 🏆 Best Result

After feature engineering, **Logistic Regression** achieved the best overall performance:

- **Accuracy:** 88%
- **Precision:** 78.46%
- **Recall:** 83.61%
- **F1 Score:** 80.95%
